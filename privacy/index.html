The consultation form

The form asks for your name, your email address, an optional company or business name, and a message.

Please do not send passport or driving-licence scans, passwords, National Insurance numbers, or a full set of tax records in the first message. If we take the work on, we will tell you how to send documents.

There is a hidden field used to catch automated spam. If it is filled in, the page does not send the form.

The page sends the form, using JavaScript, to our enquiry service at accology-enquiry.accology.workers.dev. The connection to that service is encrypted. If JavaScript is turned off, the form is not sent, and the page asks you to email us instead.

Visit information we record ourselves

When a page loads, the browser sends three things to that same enquiry service: the page path (for example /pricing/), the host name, and the referring page if your browser supplies one. A normal web request also carries an IP address and a browser type. The script on the page does not set a cookie.

Cloudflare Web Analytics

These pages load a Cloudflare Web Analytics beacon from static.cloudflareinsights.com. We use it to see whether the pages load properly. Cloudflare's current documentation for this product says it does not use cookies or similar storage in the browser, and that it collects page-performance information rather than a profile of you.

Cookies

This website does not set its own cookies. There is no advertising cookie, and there is no cookie banner.

Cloudflare's documentation for Web Analytics says the beacon does not use cookies. The consultation form, as written on these pages, does not use a cookie either. You can block cookies in your browser. The pages still work if you do.

Why we use the information, and the lawful basis

We use the form to reply, to see whether we can help, and to take the steps you ask for before any contract. The basis we expect to rely on is Article 6(1)(b) of the UK GDPR (steps before a contract).

We record page visits so we can see which pages are used and keep the site working. The basis we expect to rely on is Article 6(1)(f), legitimate interests. The information is limited to the page, the referrer and the technical details of the request. You can object. Email contact@accology.co with the subject “Objection to visit log”.

We do not use a consent tick box, and this form does not add you to a mailing list.

Your rights

You can ask us to:

  • Give you a copy of the personal information we hold about you
  • Correct it
  • Delete it, where the law allows
  • Restrict how we use it
  • Object to use based on legitimate interests, including the visit log
  • Provide the information you gave us in a portable form, where the law gives that right. It can apply to the consultation form if we rely on steps before a contract

We may need to check it is you before we act. We aim to reply within one month. There is no fee for a normal request. We are not relying on consent for this website, so there is no consent to withdraw. You can still ask us to delete an enquiry.

Complaints
